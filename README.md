## 🧩 Lab Format

Each lab in `docs/` follows the same structure:

- **Objective** — what's being demonstrated and why it matters
- **Topology** — diagram + device list, IP scheme
- **Configuration** — key CLI config snippets per device
- **Verification** — `show` command output confirming it works
- **Troubleshooting Scenario** — an intentional fault, diagnosed and resolved
- **What I Learned** — brief reflection
